# MacDuo

把 MacBook 的内建屏变成一块会随盖角折过去的屏：**截全屏 → 底黑 → 把截图拉成上窄下宽的梯形
（底边不动）→ 从顶端往下套一层逐渐减弱的高斯模糊。**

```
盖角 90°            约 67°             约 45°             约 22°
┌────────┐         ┌────────┐         ╱────────╲         ╱──────╲
│  清晰  │   →     │ 略模糊 │   →     │  模糊  │   →     │ 很模糊 │
└────────┘         └────────┘         └────────┘         └────────┘
   矩形               轻微收窄           明显梯形           更窄更糊
```

- **底边永不动**：只有上面两个角随着合盖往里收，画面被拉伸填满这个梯形，不裁切。
- **梯形之外是黑色空间**：但和 iPhone Duo 参考一样，图片边缘也参与模糊，会在黑色里留下一圈自然的散射。
- **模糊自上而下递减、横向覆盖整屏**：顶端最强、每行左中右同时生效；到铰链端降到 0。
- **只在下半程有效果**：盖角 0–90° 之间生效，越合越强，90° 及以上画面完全干净（探针实测此时
  输出与捕获帧逐像素一致，差异 0.000%）。

## 用法

```bash
./build.sh             # 编译并打包出 dist/MacDuo.app
open dist/MacDuo.app   # 启动，菜单栏出现一个角度图标
```

首次运行要在 **系统设置 → 隐私与安全性 → 屏幕录制** 里勾选 MacDuo（需要读屏幕内容）。
**每次 `./build.sh` 之后都要重新授权**：ad-hoc 签名的 cdhash 每次构建都会变，macOS 会当成新 App。

菜单栏下拉里：开关效果、顶端收窄量、生效角度、**预览一次开合（8.6 秒，不用真去合盖子）**、
开始/停止画面捕获、重新检测传感器、打开设置、退出。

设置窗口分三页：

| 页 | 参数 |
| --- | --- |
| 效果 | 顶端收窄量、顶端模糊半径、渐变曲线；远端压暗（默认跟随参考效果）/ 白雾 / 保留色彩 |
| 角度 | 开始生效角度（默认 90°）、满强度角度（默认 0°）、响应曲线、响应平滑、镜像 |
| 硬件 | 角度偏移 / 角度倍率（读数不对或方向相反时校准）、传感器与捕获状态 |

## 排错

- **合盖没反应**：看菜单栏图标。橙色感叹号 = 缺屏幕录制权限；「画面捕获」显示未启动就先授权，
  再从菜单点一下「开始画面捕获」。
- **传感器读不到**：2019 款 16" MacBook Pro 之后才有这个传感器；部分 M1/M2 机型以私有 HID
  接口暴露，读不到。合盖模式（接外接屏）下内建屏关闭，同样不可用。
- **方向反了**：设置 →「硬件」→ 打开「反转角度方向」。
- **只有内建屏受影响**，外接显示器不会有任何效果。

### 已知限制

- 用别的录屏/截图工具记录时会录到模糊后的画面——覆盖窗口本身就是屏幕内容（只有本应用自己的
  捕获会排除它）。
- 覆盖窗口是 `.normal` 层级 + `canJoinAllSpaces`，全屏 App 可能盖在它上面。
- 覆盖层显示的是"截图"，所以画面内容会比现实落后一两帧（这是"先截图再变换"这个做法的固有代价）。
